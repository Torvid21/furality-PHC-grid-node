## Furality Grid Node

A gridnode generator for sending DMX control over video. Used in Furality worlds and other projects. It's meant to be very direct and minimal, with features and formats only added as-needed. If you are looking for something more modular, check out [hnode](https://github.com/Happyrobot33/HNode).

Exports video via [Spout2](https://github.com/leadedge/Spout2).

## Usage

Compatible ArtNet lighting software or network hardware is required.

[OBS](https://obsproject.com/) with the [Spout2 Plugin](https://github.com/Off-World-Live/obs-spout2-plugin) can be used to record or transmit.

## Building

This project is pre-configured for [Visual Studio 2022 CE](https://visualstudio.microsoft.com/vs/), but should build fine on any recent version.
